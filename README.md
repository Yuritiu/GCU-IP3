Controls

Left Click	Select Cards / Remove Cards from Table / Select Opponent / Hold Knife to Cut Finger / Fire Revolver

Right Click	Prime Revolver before Firing

ESC

Pause Menu

Mouse

Freelook / Move Left and Right to Cut Finger Off

Space Skip Scene / Skip Dialogue
